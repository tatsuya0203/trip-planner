1. ファイル名: [ローマ字].json (例: aichi.json)
2. データ構造:
{
  "name": "[都道府県名]",
  "id": "[ローマ字ID]",
  "transitData": { "message": "移動時間の目安..." },

      "area": "エリア名（例：名古屋市内）",
